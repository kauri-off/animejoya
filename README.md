# AnimeJoy

Минималистичный десктоп-клиент для animejoya.ru: Tauri 2 + React 19 + Rust.

Ссылки на тайтлы вставляются вручную (`Ctrl+V` в окне библиотеки) — приложение
подтягивает обложку, описание и список серий, качает mp4 с докачкой и запускает
внешний плеер (`mpv` по умолчанию).

## Запуск

```bash
npm install
npm run tauri dev      # разработка
npm run tauri build    # AppImage + deb
```

## Настройки

Хранятся в `~/.config/animejoya/`:

- `config.json` — логин/пароль от сайта, папка для серий, плеер;
- `library.json` — библиотека тайтлов и отметки о просмотре.

Переменные окружения перекрывают конфиг: `ANIMEJOYA_DIR`, `ANIMEJOYA_PLAYER`.

## Устройство

- `src-tauri/site.rs` — авторизация, ajax-плейлист, разбор `data-file`;
- `src-tauri/download.rs` — потоковая загрузка с докачкой и отменой;
- `src-tauri/player.rs` — запуск внешнего плеера и файлового менеджера;
- `src/` — интерфейс: библиотека, карточка тайтла, очередь загрузок.
