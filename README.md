# AnimeJoy

Минималистичный клиент для animejoya.ru: локальный сервер на Bun + React 19.
Интерфейс открывается во вкладке твоего браузера — своего движка приложение не тащит.

Ссылки на тайтлы вставляются вручную (`Ctrl+V` в окне библиотеки) — приложение
подтягивает обложку, описание и список серий, качает mp4 с докачкой и показывает
серии во встроенном плеере (Vidstack) или во внешнем (`mpv` по умолчанию).

## Запуск

```bash
npm install
npm run compile   # собирает одиночный бинарник ./animejoya
./animejoya       # поднимает сервер и открывает браузер
```

## Разработка

Нужны два терминала: сервер и Vite с горячей перезагрузкой.

```bash
npm run dev:server   # API на 127.0.0.1:7788
npm run dev          # интерфейс на 127.0.0.1:1420, /api проксируется на сервер
```

## Релиз

Actions → build → Run workflow, в поле «Тег релиза» — `v1.2.3`. Бинарники для Linux и
Windows соберутся и лягут в релиз (по умолчанию черновиком). Пуш тега `v*` делает то же самое.

## Настройки

Хранятся в `~/.config/animejoya/`:

- `config.json` — логин/пароль от сайта, папка для серий, плеер;
- `library.json` — библиотека тайтлов и отметки о просмотре.

Переменные окружения перекрывают конфиг: `ANIMEJOYA_DIR`, `ANIMEJOYA_PLAYER`,
`ANIMEJOYA_PORT` (по умолчанию 7788), `ANIMEJOYA_NO_OPEN` (не открывать браузер).

## Устройство

- `server/site.ts` — авторизация, ajax-плейлист, разбор `data-file`;
- `server/download.ts` — потоковая загрузка с докачкой и отменой;
- `server/player.ts` — запуск внешнего плеера и файлового менеджера;
- `server/media.ts` — `/media/*` для встроенного плеера: файлы с диска и прокси CDN
  с нужным Referer, оба с поддержкой Range;
- `server/index.ts` — HTTP-роуты, поток событий (SSE), раздача статики;
- `src/` — интерфейс: библиотека, карточка тайтла, очередь загрузок.

Сервер слушает только `127.0.0.1` и отклоняет запросы с чужими `Host` и `Origin`,
чтобы на него не мог постучаться сайт, открытый в соседней вкладке.
