# AnimeJoy

Минималистичный клиент для animejoya.ru: локальный сервер на Bun + React 19.
Интерфейс открывается во вкладке твоего браузера — своего движка приложение не тащит.

Ссылки на тайтлы вставляются вручную (`Ctrl+V` в окне библиотеки) — приложение
подтягивает обложку, описание и список серий и показывает серии во встроенном плеере
(Vidstack) потоком через сервер. Следующая серия заранее ложится во временный кэш,
а «Скачать» отдаёт mp4 менеджеру загрузок браузера.

Кнопка «Продолжить» на странице тайтла запускает первую непросмотренную серию, на карточках
библиотеки виден прогресс. Тайтл открывается по адресу вкладки, так что «Назад» и F5 работают
как на обычном сайте. Горячие клавиши — по `?`.

## Запуск

```bash
npm install
npm run compile   # собирает одиночный бинарник ./animejoya
./animejoya       # поднимает сервер и открывает браузер
```

## Разработка

Нужны два терминала: сервер и Vite с горячей перезагрузкой.

```bash
npm run dev:server   # API на 127.0.0.1:7788
npm run dev          # интерфейс на 127.0.0.1:1420, /api проксируется на сервер
```

## Релиз

Actions → build → Run workflow, в поле «Тег релиза» — `v1.2.3`. Бинарники для Linux и
Windows соберутся и лягут в релиз (по умолчанию черновиком). Пуш тега `v*` делает то же самое.

## Настройки

Хранятся в `~/.config/animejoya/`:

- `config.json` — логин/пароль от сайта;
- `library.json` — библиотека тайтлов и отметки о просмотре.

Переменные окружения:

- `ANIMEJOYA_HOST` / `ANIMEJOYA_PORT` — адрес и порт (по умолчанию `127.0.0.1:7788`);
- `ANIMEJOYA_HOSTS` — внешние домены через запятую, под которыми открывают сервер;
- `ANIMEJOYA_CACHE` — папка предзагрузки (по умолчанию `<tmp>/animejoya`);
- `ANIMEJOYA_CACHE_HOURS` / `ANIMEJOYA_CACHE_GB` — срок жизни и предел кэша (12 ч, 10 ГБ);
- `ANIMEJOYA_NO_OPEN` — не открывать браузер при старте.

## За Caddy

Сервер остаётся на петле, Caddy терминирует TLS и закрывает вход паролем —
у самого приложения авторизации нет.

```caddyfile
anime.example.com {
	basic_auth {
		me <хеш из `caddy hash-password`>
	}
	reverse_proxy 127.0.0.1:7788
}
```

```bash
ANIMEJOYA_HOSTS=anime.example.com ANIMEJOYA_NO_OPEN=1 ./animejoya
```

## Docker

Образ `ghcr.io/kauri-off/animejoya` (amd64 и arm64) собирается workflow `docker`
на каждый пуш в master (`latest`) и тег `v*` (`1.2.3`, `1.2`).

```bash
ANIMEJOYA_HOSTS=anime.example.com docker compose up -d
```

Контейнер слушает `127.0.0.1:7788` для Caddy на хосте; конфиг и библиотека
лежат в томе `data`, кэш предзагрузки — в томе `cache`.

## Устройство

- `server/site.ts` — авторизация, ajax-плейлист, разбор `data-file`;
- `server/download.ts` — предзагрузка серии с докачкой и отменой;
- `server/cache.ts` — временный кэш предзагрузки и его очистка по сроку и размеру;
- `server/media.ts` — `/media/*`: файлы из кэша и прокси CDN с нужным Referer,
  оба с Range; с `name` отдаются вложением для загрузки браузером;
- `server/index.ts` — HTTP-роуты, поток событий (SSE), раздача статики;
- `src/` — интерфейс: библиотека, карточка тайтла, очередь загрузок.

Сервер слушает только `127.0.0.1` и отклоняет запросы с чужими `Host` и `Origin`,
чтобы на него не мог постучаться сайт, открытый в соседней вкладке.
